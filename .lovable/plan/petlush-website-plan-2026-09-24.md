# PetLush website plan

## Build
- Replace the blank home page with a complete PetLush experience using the requested modern claymorphism direction, warm pastel palette, friendly typography, and premium pet-focused imagery.
- Add a responsive navigation system and all requested content areas: Home, All Pets, Care Guide, Safety, Services, Gallery, Pet Tips, About, Contact, FAQ, and Footer.
- Add working search, pet filters, an interactive pet selector, rotating care tips, gallery lightbox, smooth scrolling, mobile menu, and back-to-top control.
- Keep all care copy general and clearly non-diagnostic; use placeholders rather than invented business contact details.

## Visual system
- Define semantic cream, green, peach, blue, and clay-surface tokens in the global style system.
- Use soft dimensional shadows, tactile rounded controls, restrained motion, and accessible contrast without falling back to a generic template.
- Generate a cohesive set of original pet imagery for the main visual and gallery.

## Technical details
- Keep the existing TanStack React structure and use Bootstrap 5 utilities/components through the package where practical, with custom semantic styling for the distinctive look.
- Build accessible controls with keyboard support, named icon buttons, focus states, reduced-motion handling, and mobile-first responsive layouts.
- Add route-specific metadata, verify the preview at desktop and mobile sizes, and check the final build signal.
