# PetLush: Elevating Pet Care

Create a premium responsive pet-care website named PetLush 🐾 with the tagline “Elevating Pet Care with Love.”

Style: Modern Claymorphism — soft 3D cards, rounded UI, pastel green/cream/peach/blue palette, beautiful pet images, friendly typography, subtle animations.

Sections:
Home/Hero • All Pets • Care Guide • Safety • Services • Gallery • Pet Tips • About • Contact • Footer.

Pets: 🐶 Dogs, 🐱 Cats, 🐰 Rabbits, 🐦 Birds, 🐠 Fish, 🐹 Hamsters, 🐢 Turtles, 🦜 Parrots.

Features: Search, pet filters, interactive pet selector, gallery lightbox, rotating care tips, FAQ, smooth scrolling, hover effects, mobile menu, back-to-top.

Care topics: Food • Health • Grooming • Activities • Safety.

Use HTML, CSS, JavaScript, Bootstrap 5. Make it mobile-first, accessible, fast and easy to navigate.

Do not invent medical claims or real business details.

Make PetLush feel creative, warm, premium and memorable, not like a generic template.
